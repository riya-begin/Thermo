# Thermo
 # 🚀 Mobile Thermodynamics Architecture

A collection of physical chemistry computing tools developed, tested, and deployed entirely on **Android**. 

## 📱 Developer Note (100% Android Workflow)
> ⚠️ **Proud Note:** I am building this project as a **beginner using nothing but an Android device**. To keep the code modular and clean, each calculator lives in its own dedicated Git branch.

## 🌿 Repository Branch Structure
Instead of hosting everything in one folder, switch between branches using the GitHub branch dropdown menu above:

* **`interactive-calculator` Branch:** Contains the primary interactive thermodynamics script tracking \(\Delta G\) and spontaneity flips.
* **`vant-hoff-calculator` Branch:** Contains the equilibrium shift modeling (\(K_{eq}\)) based on the Van 't Hoff equation.
